# SAO extension catalog

Generated from verified, manually published release APKs. Install/update supported sources inside SAO, or use the [download page](index.html). Releases use the same publisher certificate as the [SAO release](https://github.com/nijuyonkadesu/SAO/releases/tag/v1.2.0).

> [!WARNING]
> Development/debug APKs use a different certificate. Back up settings and source data, then uninstall those builds before installing release APKs.

Implementation and publishing instructions: [main branch](https://github.com/nijuyonkadesu/SAO-extensions/tree/main).
